# First baseline — 2026-11-11

TF-IDF + logistic regression (`chopcast-train baseline` defaults), 80/20 split, seed 42.
Data: live collector DB, Aug 28 – Nov 11 2026. Dataset `parser-v2_labeler-v2_cleaner-v2_features-v1`.

| Run | Rows | Macro-F1 | Accuracy | Majority floor |
|---|---|---|---|---|
| A. Labeled only, full text, stratified (**headline**) | 45,955 | **0.589** | 0.550 | 0.351 |
| B. Same, time-ordered split | 45,955 | 0.542 | 0.530 | 0.352 |
| C. All pilot reports, no /TB counted as None | 82,547 | 0.628 | 0.708 | 0.624 |
| D. Labeled, severity words stripped from /RM | 45,955 | 0.579 | 0.539 | 0.351 |
| E. Labeled, header only (aircraft, altitude band, hour) | 45,955 | 0.317 | 0.387 | 0.351 |

Labels (labeled set): Light 16,148 · None 15,124 · Moderate 14,411 · Severe 272.

## What this says

- The signal is in the text, not the header: header-only (E) barely beats the floor.
- Counting reports with no /TB as None (C) inflates accuracy by mostly predicting None. Train on labeled reports.
- /RM leakage (issue #3) is small: stripping it costs 0.01 macro-F1.
- Time split (B) is 0.05 lower than stratified, so expect some drift over time.
- Severe F1 (0.71) is mostly the `UUA` (urgent PIREP) header: 225 of 272 Severe reports are UUA.
  This is close to a label leak and needs a decision before trusting Severe scores.
